# ai-fanout.com

Public source repository for the future `ai-fanout.com` website.

## Current state

Repository and Vercel foundation only. The planned public tool, reference, service, or publication is not launched on the custom domain yet. The temporary deployment is deliberately excluded from indexing.

## Standalone purpose

This project is intended to publish versioned observations, datasets and methodology only after a repeatable research protocol has been proven.

## Current status

Research incubator. No public dataset or trend claim is available yet.

## Hard boundary

The site must not claim access to hidden queries, private retrieval traces or model reasoning. It stays noindex until the launch gate is met.

Primary portfolio relationship: `Contextter (accepted)`.

## Local development

```bash
corepack pnpm install
corepack pnpm dev
```

Verification:

```bash
corepack pnpm verify
```

## Deployment

Vercel project: `ai-fanout-com`.

The placeholder carries both a robots exclusion and an `X-Robots-Tag`. Remove those only when the real site passes its strategy, rights, disclosure, quality, and launch gates. Connecting the custom domain and changing DNS are separate operations.
