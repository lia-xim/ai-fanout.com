# Controlled Signal

## Accepted direction

A premium, modern evidence interface built around one idea: **controlled signal**. The website uses a calm near-black field, cool-white type, precise graphite rules, cyan for observable evidence and restrained red only for open or blocked states. It behaves like an inspectable instrument, not a faux paper, terminal or generic SaaS dashboard.

The Evidence Lab extends the system into a browser-local workbench: ruled input stages, visible method boundaries, source and coverage matrices, and portable outputs. The library remains the typographic reference layer behind those tools. The system avoids article cards, decorative dashboards and interchangeable blog templates.

## Selected design skills

- `premium-frontend-ui`: foundational direction for an authored first viewport, coherent hierarchy, deliberate editorial rhythm and a credible tool surface.
- `redesign-existing-projects`: guided the product-level evolution from a library-first site into a tool-first workbench while preserving the accepted Controlled Signal identity.
- `impeccable-design-polish`: final audit of hierarchy, spacing, anti-slop, responsive composition, form states, result matrices and accessibility hardening.
- `frontend-testing-debugging`: production browser verification at desktop and mobile sizes, including tool interactions, library filtering, navigation, overflow and runtime state.

Deliberately rejected: `frontend-design`, `minimalist-ui`, `industrial-brutalist-ui` and `od-crazy-websites` because a second foundational aesthetic would dilute the system; all GSAP and motion skills because data entry, matrix inspection and reading flow need no choreographed animation; image generation because code-native composition is the domain-specific visual asset.

## Component rules

- Maximum surface width: `96rem`; horizontal gutter follows `clamp(1.25rem, 4vw, 4.5rem)`.
- Open bands, rails, lists and tables are preferred over cards.
- The illustrative source-recurrence matrix is the homepage signature composition.
- The Evidence Lab is the signature interaction; the Protocol Builder is its planning counterpart.
- The Library Index remains the signature research-navigation composition.
- Article pages use one direct-answer band, one sticky evidence spine and one source register.
- Cyan is semantic: observable evidence, current navigation and active controls.
- Red is semantic: open gates and unobserved/private boundaries.
- Borders stay square and precise; circles are reserved for steps and state nodes.
- No decorative eyebrow, status pill, proof badge, fake chart, fake metric, glass panel, glow field or bento grid.

## Responsive composition

- Desktop tools: asymmetric page head; staged ruled forms; metric rail and paired evidence matrices. Desktop library: filterable ruled index and persistent evidence spine.
- Mobile tools: single-column input sequence, full-width local-only state, two-column metrics and horizontally contained matrices. Mobile library retains its intentional editorial composition.
- Detail titles use intentional wrapping rather than scaled desktop leftovers.
- Minimum target size: 44px. No horizontal page scroll at 320px.

## Motion and accessibility

- Motion clarifies entrance, selection and directional hover only.
- Native labels and controls, inline validation, `aria-live` result regions and readable table semantics are mandatory.
- Category filters use native buttons and `aria-pressed`; filtered results retain ordinary crawlable links.
- No scroll hijacking, pinning, infinite animation or custom cursor.
- `prefers-reduced-motion: reduce` collapses non-essential animation and transitions.
- Native landmarks, keyboard-operable controls, visible focus rings, high-contrast text, breadcrumbs and semantic source lists remain mandatory.

## Rendered proof

- Desktop homepage: 1440×1000, authored split hero and illustrative four-row recurrence matrix, no overflow.
- Desktop Lab: synthetic three-observation run produced 3 source domains, 2 recurring domains, 62% mean pairwise token overlap and 12/12 literal matches; paired matrices and four comparability notes rendered with no runtime or console problems.
- Mobile Protocol Builder: 390×844, native menu, generated Markdown preview, eight readiness signals with five satisfied by the synthetic plan, no overflow.
- Library regression: 13 references, six filters, Method filter 4 visible / 9 hidden.
